# C#-скрипты Hell Tower

Здесь опубликованы C#-скрипты раннего технического прототипа Hell Tower, созданного в Unity 6.5 с использованием Codex в AI-assisted процессе.

Код отражает текущее состояние прототипа и предназначен для демонстрации реализованных механик и подхода к итеративной разработке. Полный Unity-проект, сцены, настройки и сторонние графические ассеты в репозиторий не включены.

## Структура

- `Player` — передвижение, здоровье, агро-зона и автоматическая атака героя;
- `Enemy` — здоровье, NavMesh-перемещение, выбор цели и атака противников;
- `CoreTower` — здоровье центральной башни и управление HUD;
- `Combat` — снаряд и временный эффект попадания;
- `Systems` — условие поражения и остановка игры;
- `UI` — ориентация World Space-интерфейса относительно камеры.

## Статус

Это учебный ранний прототип. Архитектура и производительность будут пересматриваться по мере роста проекта: планируются событийное обновление интерфейса, уменьшение количества поисков объектов в сцене и повторное использование создаваемых объектов вместо постоянных `Instantiate`/`Destroy`.
